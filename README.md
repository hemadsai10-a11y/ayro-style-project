# AyroStyle

A modern responsive digital agency website built with React, Vite, Bootstrap, Tailwind CSS, Node.js and Express.

## Features

- Responsive navigation
- Hero section
- Features section
- About section
- Services section
- Portfolio section
- Testimonials section
- Contact form
- Node.js and Express backend
- Contact form API
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- React.js
- Vite
- Bootstrap
- Tailwind CSS
- Node.js
- Express.js
- Git
- GitHub
